A network security lab you SSH into.

Shabakah is one self contained Docker container. You start it, SSH in, and a guide greets you and takes you through ten hands on lessons in network security.

Every lesson has a real practice target running inside the box, a challenge, and a checker that verifies your answer live. Nothing reaches the outside world, so you can practise scanning, capture and enumeration safely, in English or Arabic.

git clone https://github.com/SiteQ8/Shabakah.git
cd Shabakah
docker compose up -d --build
ssh -p 2222 learner@localhost

The default password is shabakah. Set LEARNER_PASSWORD to change it.

docker run -d --cap-add NET_ADMIN -p 2222:22 ghcr.io/siteq8/shabakah:latest

Or pull the prebuilt image. NET_ADMIN is only needed for the firewall lesson.

How it works

  1. Start the container

    One image on Debian with the tools already installed. The practice targets start with it, all bound to loopback inside the box.

  2. Connect over SSH

    Log in as learner on port 2222. The guide opens on its own, and you can leave it for a normal shell at any time.

  3. Learn by doing

    Read a lesson, run the commands against the targets, then check your answer. The guide records what you have completed.

The ten lessons

Each lesson explains one idea, shows the commands, says why a defender cares, and ends with a challenge the guide can verify against the live targets.

  1. The network stack and sockets
  2. Reading the wire with tcpdump
  3. Port scanning with nmap
  4. Service enumeration and banners
  5. HTTP recon and cleartext exposure
  6. DNS reconnaissance
  7. TLS and certificates
  8. Host firewalling
  9. Traffic analysis and spotting attacks
  10. Detection and hardening

The practice targets

Four small services run inside the container so there is always something real to scan, capture and inspect.

  • 8080HTTPA deliberately careless web service for header, banner and cleartext analysis. It leaks a credential on purpose.
  • 8443HTTPSA TLS service with a self signed certificate to inspect with openssl.
  • 9000Raw TCPA banner service that answers a few commands, for enumeration practice with netcat.
  • 5353DNSA small resolver serving a practice zone with A, MX and TXT records.

The guide

It opens when you log in. Type netsec to reopen it from a shell, or use it directly:

netsec lessons
list all lessons
netsec lesson 03
read one lesson
netsec check 03 8080,8443,9000
check a challenge answer
netsec targets
show lab target status
netsec cheat
command cheat sheet
netsec progress
show your progress
netsec lang ar
switch the guide to Arabic

Safety and scope

This lab exists for learning on systems you own or are authorised to test. Only scan the local practice targets. The container attacks nothing outside itself, and its tools should not be pointed at hosts you do not have permission to test.

كيف يعمل

  1. شغّل الحاوية

    صورة واحدة على Debian بالأدوات مثبتة مسبقا، وتنطلق أهداف التدريب معها وكلها مرتبطة بالاسترجاع داخل الحاوية.

  2. اتصل عبر SSH

    ادخل بالمستخدم learner على المنفذ 2222 فيفتح المرشد من تلقاء نفسه، وتستطيع مغادرته إلى طرفية عادية في أي وقت.

  3. تعلّم بالممارسة

    اقرأ درسا ثم شغّل الأوامر على الأهداف ثم تحقق من إجابتك، ويسجّل المرشد ما أكملته.

الدروس العشرة

يشرح كل درس فكرة واحدة ويعرض الأوامر ويبيّن لماذا يهتم المدافع، ثم يختم بتحدٍّ يستطيع المرشد التحقق منه على الأهداف الحية.

  1. طبقات الشبكة والمقابس
  2. قراءة حركة الشبكة باستخدام tcpdump
  3. فحص المنافذ باستخدام nmap
  4. تعداد الخدمات والترويسات الافتتاحية
  5. استطلاع HTTP وخطر النص الصريح
  6. استطلاع نظام أسماء النطاقات
  7. بروتوكول TLS والشهادات
  8. الجدار الناري على المضيف
  9. تحليل الحركة واكتشاف الهجمات
  10. الكشف والتحصين

أهداف التدريب

تعمل أربع خدمات صغيرة داخل الحاوية كي يكون هناك دائما شيء حقيقي تفحصه وتلتقطه وتتفحصه.

  • 8080HTTPخدمة ويب مهمِلة عن قصد لتحليل الترويسات واللافتات والنص الصريح، وهي تسرّب بيانات اعتماد عمدا.
  • 8443HTTPSخدمة TLS بشهادة موقّعة ذاتيا لفحصها بأداة openssl.
  • 9000TCP خامخدمة لافتات تجيب عن بضعة أوامر لتدريب التعداد بأداة netcat.
  • 5353DNSخادم أسماء صغير يخدم نطاقا تدريبيا بسجلات A وMX وTXT.
