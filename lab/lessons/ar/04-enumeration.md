# تعداد الخدمات والترويسات الافتتاحية

إيجاد منفذ مفتوح هو البداية، أما التعداد فهو عمل يجعل الخدمة تخبرك بما هي وما إصدارها وما الذي تسمح لك به، وأكثر ذلك مجرد حوار متأنٍّ.

## أدوات متعددة الاستعمال

- يفتح **netcat** أي `nc` اتصال TCP خام كي تقرأ لافتة أو تكتب بروتوكولا يدويا.
- يفعل **socat** الشيء نفسه بقدرة أكبر تشمل الاتصالات المغلّفة بـ TLS.
- يتحدث **curl** بروتوكول HTTP على وجهه الصحيح ويعرض لك الترويسات.

## التقاط اللافتة الافتتاحية

كثير من الخدمات تحيّيك لحظة اتصالك، وهذه التحية أي **اللافتة** كثيرا ما تسرّب المنتج والإصدار.

```
nc 127.0.0.1 9000
```

اكتب أمرا بعد اتصالك، فهذه الخدمة تفهم عددا قليلا منها.

```
HELP
VERSION
WHOAMI
QUIT
```

أما في HTTP فتعيش اللافتة في ترويسات الاستجابة لا في تحية افتتاحية.

```
curl -sI http://127.0.0.1:8080
```

## لماذا يهتم المدافع

يعدّد المهاجمون كي يخططوا، فإذا أعطت اللافتة إصدارا دقيقا أعطت قائمة قصيرة بالثغرات المعروفة، وتقليم اللافتات أو إخفاؤها لا يوقف المختبِر المصمّم لكنه يبطئ العابث ويعدّ نظافة أساسية، والأهم أن تعدّد خدماتك بنفسك كي تعرف ما تكشفه.

## جرّب بنفسك

اتصل بالمنفذ 9000 عبر netcat واقرأ ما ترسله قبل أن تكتب شيئا، ثم اطلب منها إصدارها واقرأ الرد، فرمز الإصدار يبدو حرف v صغيرا يتبعه رقم.
